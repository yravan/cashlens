## Product thesis

Cash Lens is intended to be a personal financial operating system, not just a transaction category viewer.

The core primitive should be a normalized ledger that can later be enriched with:

- receipts
- line items
- reimbursements
- returns
- claims
- recurring obligations
- predictions
- reviewable intelligence

## North-star questions preserved

- Where did my money go?
- Where did money come from?
- What is my true spending?
- What do I owe and what am I owed?
- What changed unexpectedly?
- What is my financial state right now?

## Phase guidance preserved

- Phase 0: product skeleton and schema
- Phase 1: Plaid sandbox to real sync
- Phase 2: manual categorization and rules
- Phase 3: reimbursements, returns, and true spend
- Phase 4+: receipts, smarter categorization, recurring detection, mobile, broader import coverage

## Important wedge

The differentiator is not “prettier Monarch.”
The wedge is:

- true spend
- reimbursements
- returns
- receipts
- review queue
- learn-from-corrections behavior
